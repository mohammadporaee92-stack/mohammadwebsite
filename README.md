# PorAI — محمد پورائی | Mohammad Poraee

وب‌سایت شخصی دوزبانه برای آموزش کاربردی هوش مصنوعی و اتوماسیون به افراد علاقه‌مند، با حفظ طراحی سرمه‌ای و آبی پروژهٔ موجود.

این شاخه نسخهٔ پیشنهادی برای بررسی است. تغییر کد در گیت‌هاب به‌تنهایی به معنی انتشار روی سایت اصلی نیست.

## محتوای این نسخه

- عکس واقعی صاحب سایت و لینک اینستاگرام و تلگرام `@mohammad_por_ai`.
- شش آموزش متنی فارسی و انگلیسی: شروع با AI، درخواست روشن، خلاصه‌سازی، برنامه‌ریزی روزمره، بررسی پاسخ و طراحی نقشهٔ اتوماسیون.
- یک دورهٔ رایگان با همین شش درس، تمرین و امکان ذخیرهٔ پیشرفت.
- یک یادداشت شروع یادگیری و سه معرفی ابزار با لینک منبع رسمی.
- پروژه‌ها فعلاً خالی هستند. آمار ساختگی کاربران و نمونه‌پروژه‌های قبلی نمایش داده نمی‌شوند.

مطالعهٔ آموزش‌ها و درس‌های رایگان به حساب کاربری نیاز ندارد. ثبت‌نام اختیاری با نام، موبایل و رمز برای ذخیرهٔ پیشرفت و علاقه‌مندی‌هاست؛ تأیید مالکیت شماره با پیامک انجام نمی‌شود. ورود و بازیابی پیامکی غیرفعال‌اند و هیچ کد نمایشی صادر نمی‌شود.

پنل موجود مدیریت محتوا، دوره‌ها، کاربران، پیام‌ها، خبرنامه و تنظیمات حفظ شده است. فرم‌های تماس و همکاری و عضویت خبرنامه داده را در SQLite ذخیره می‌کنند؛ ایمیل یا پیامک خودکار ارسال نمی‌شود. پرداخت و ثبت‌نام دورهٔ پولی تا پیاده‌سازی تأیید واقعی تراکنش غیرفعال می‌ماند.

## اجرای محلی

محیط آزمون این نسخه Node.js 24 است. پروژه از Next.js، React و SQLite داخلی Node استفاده می‌کند.

```bash
npm ci
cp .env.example .env
node -e 'console.log(require("node:crypto").randomBytes(32).toString("hex"))'
```

مقدار تصادفی تولیدشده را در `SESSION_SECRET` قرار بده. سپس:

```bash
npm run db:seed
npm run dev
```

آدرس‌های محلی `/fa` و `/en` روی `http://localhost:3000` در دسترس‌اند. برای ساخت نسخهٔ production:

```bash
npm test
npm run build
npm start
```

## ساخت حساب مدیر

حساب مدیر از فرم عمومی ساخته یا ارتقا داده نمی‌شود. در محیط محلی یا ترمینال امن سرور، شمارهٔ صاحب سایت را در `ADMIN_PHONES` رزرو کن. سپس `ADMIN_BOOTSTRAP_PHONE` و یک رمز یکتا با طول ۱۲ تا ۱۲۸ کاراکتر را در محیط قرار بده و اجرا کن:

```bash
npm run admin:create
```

بعد از ساخت حساب، `ADMIN_BOOTSTRAP_PASSWORD` را پاک کن و از صفحهٔ ورود عادی وارد `/fa/admin` شو. فرمان در صورت وجود حساب قبلی متوقف می‌شود و آن را تغییر نمی‌دهد. نقش حساب‌های موجود از طریق مدیر فعلی مدیریت می‌شود. بازیابی رمز بدون پیامک نیازمند رسیدگی مالک سایت است؛ مسیر نمایشی یا دورزنندهٔ احراز هویت وجود ندارد.

## به‌روزرسانی دیتابیس موجود

پیش از اجرای نسخهٔ جدید، از دیتابیس و فایل‌های آپلودشده پشتیبان معتبر بگیر. هنگام بکاپ SQLite، برنامه را متوقف کن یا از روش بکاپ سازگار با SQLite استفاده کن؛ کپی تنها فایل اصلی هنگام فعال بودن WAL کافی نیست.

```bash
npm run brand:refresh
```

این فرمان در یک تراکنش محتوای شروع را اضافه می‌کند. در اجرای اول، نمونه‌های شناخته‌شدهٔ نسخهٔ قبلی که در `src/lib/seeds/legacy.json` آمده‌اند و معرفی ابزارها/یادداشت‌های نمایشی قبلی به پیش‌نویس تبدیل می‌شوند؛ رکوردها حذف نمی‌شوند. متن برند و لینک‌های اجتماعی در اجرای اول با مشخصات این نسخه جایگزین می‌شوند.

شناسهٔ درس‌ها، ثبت‌نام‌ها، پیشرفت و ذخیره‌های کاربران حفظ می‌شوند. اجرای مجدد، ویرایش‌های مدیر را بازنویسی نمی‌کند. پیش‌نویس‌های قبلی برای بررسی در پنل باقی می‌مانند؛ هر مطلب واقعی را پس از بازبینی می‌توان دوباره منتشر کرد.

راه‌اندازی اختیاری یک دیتابیس خالی از مسیر `POST /api/setup` با هدر `Authorization: Bearer ...` و `SETUP_SECRET` ممکن است. رمز در URL قرار نمی‌گیرد؛ راه‌اندازی مجدد اجباری از راه دور وجود ندارد. برای دیتابیس موجود از فرمان محلی بالا استفاده کن.

## تنظیمات و انتشار

تنظیمات عکس، بیو، لینک‌ها و سئو در پنل مدیریت قابل ویرایش‌اند. `NEXT_PUBLIC_SITE_URL` باید دقیقاً مبدأ عمومی سایت باشد؛ این مقدار برای سئو و بررسی مبدأ درخواست‌ها استفاده می‌شود. در production از HTTPS و یک `SESSION_SECRET` یکتا استفاده کن.

این برنامه به اجرای Node و فضای ماندگار برای دیتابیس SQLite و `public/uploads` نیاز دارد. قبل از انتشار روی میزبان فعلی، ماندگاری داده و نحوهٔ اجرای migration بررسی شود. فایل‌های استقرار قبلی برای سازگاری نگه داشته شده‌اند؛ هیچ سرویس پولی در این تغییر فعال نشده است.

## اعتبارسنجی

آزمون‌ها دیتابیس موقت مستقل می‌سازند و مسیرهای واقعی ثبت‌نام، ورود، ثبت‌نام دوره، پیشرفت، ذخیره‌ها، تماس و همکاری را اجرا می‌کنند. همچنین حفظ داده در اجرای مجدد seed، جلوگیری از تصاحب شمارهٔ مدیر، لغو نشست، تغییر نقش، غیرفعال‌سازی حساب، بسته‌بودن بازیابی پیامکی و پرداخت، مبدأ درخواست و خروجی HTML بررسی می‌شوند.

بررسی ظاهری جداگانه برای صفحات فارسی و انگلیسی و عرض موبایل انجام می‌شود. آزمون‌های خودکار به دیتابیس اصلی متصل نمی‌شوند.
